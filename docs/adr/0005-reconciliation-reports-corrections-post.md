# Reconciliation reports, corrections post

Reconciliation only produces findings and never changes balances or state. A separate correction command changes the books, and it requires an operator, a reason, and an open finding or discrepancy as evidence.

Auto-correcting would be simpler, but it would let a bad report rewrite the books. A report can be wrong, and the most serious findings are the ones a person should look at. Resolving a finding changes only its triage status, so an operator can't make a payment succeed by closing a ticket.
